# บทที่ 22 Application และ Web Logging: Nginx, WordPress, Redis

Lab ในหลักสูตร: 28, 29, 30, 31

ส่ง log ของ application เข้า Graylog, เขียน rule ดักจับและบล็อก shell execution ใน WordPress, แยก log ของ Nginx กับ WordPress และเร่งความเร็ว WordPress ด้วย Redis

สิ่งที่ได้เมื่อจบบท:

- log ของ web stack แยกและค้นได้
- ตรวจจับ web shell ได้

สถานะ: กำลังเขียน ไฟล์ Lab ของบทนี้จะเพิ่มเมื่อทดสอบบนเครื่องจริงแล้ว
