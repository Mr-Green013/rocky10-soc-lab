# ไฟล์ config ของบทที่ 23

สำเนาของไฟล์ที่บทที่ 23 สร้างด้วย `sudo tee FILE <<'EOF'` จัดตาม path จริงบนเครื่อง ใช้เทียบเมื่อพิมพ์ผิด หรือคัดลอกไปวางแทนการพิมพ์ (ตรวจค่าเฉพาะเครื่อง เช่น IP และชื่อโดเมนก่อนใช้) บรรทัด comment ที่ขึ้นต้นด้วย `EN:` คือคำแปลภาษาอังกฤษของ comment ภาษาไทยบรรทัดถัดไป ไม่มีผลต่อการทำงานของไฟล์

| ไฟล์ใน repo | ตำแหน่งบนเครื่อง | หมายเหตุ |
| --- | --- | --- |
| `files/var/ossec/etc/shared/container-hosts/agent.conf` | `/var/ossec/etc/shared/container-hosts/agent.conf` | |
| `files/var/ossec/etc/shared/file-servers/agent.conf` | `/var/ossec/etc/shared/file-servers/agent.conf` | |
