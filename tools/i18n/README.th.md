# เครื่องมือดูแลสองภาษา (ไทย / อังกฤษ)

repo นี้ดูแลภาษาไทยเป็นหลัก (เพราะประกอบหนังสือภาษาไทย) และทุกส่วนมีชั้นภาษาอังกฤษกำกับ เครื่องมือชุดนี้ทำให้สองภาษาตรงกันเสมอ และจะแจ้ง error ทันทีเมื่อมีข้อความใหม่ที่ยังไม่ได้แปล

| ส่วน | ฉบับภาษาอังกฤษ | เครื่องมือ | คำแปล |
| --- | --- | --- | --- |
| เอกสาร | `X.md` (อังกฤษ) คู่กับ `X.th.md` (ไทย) มีลิงก์สลับภาษาบรรทัดแรก | `md_split.py check` | เขียนเอง |
| comment ใน script และ config | บรรทัด `EN:` อยู่เหนือ comment ภาษาไทย หรือ `(EN: …)` ต่อท้ายบรรทัดเดียวกัน | `comments.py` | `comments.en.json` |
| Diagram | `assets/diagrams/chNN/en/*.svg` + `.png` | `diagrams-en.js` | `diagrams.en.json` |
| แผนเรียน 60 วัน | `docs/study-plan.md` | `gen-studyplan-md.js` ในชุด build หนังสือ (เขียนทั้งสองภาษา) | ข้อมูลแผนเรียนฉบับภาษาอังกฤษ |

สิ่งที่ตั้งใจคงเป็นภาษาไทย: ข้อความที่ script แสดงผล และ `<description>` ของ rule Wazuh เพราะเป็น output ที่หนังสือแสดงไว้ ต้องตรงกับในเล่ม ส่วน diagram ชุดภาษาไทยคือชุดที่หนังสือใช้ และไม่ถูกแก้ไขเลย

## ตรวจก่อน commit ทุกครั้ง

```bash
python3 tools/i18n/md_split.py check       # เอกสารครบสองภาษา มีลิงก์สลับภาษา ลิงก์ไม่เสีย
python3 tools/i18n/comments.py check       # comment ไทยทุกบรรทัดมีภาษาอังกฤษกำกับ
node tools/i18n/diagrams-en.js --check     # ข้อความใน diagram ไทยทุกจุดมีคำแปล
```

## เมื่อแก้ไขส่วนต่าง ๆ

- **comment ภาษาไทยใหม่หรือที่แก้**: รัน `python3 tools/i18n/comments.py scan` เพื่อดู comment ที่ยังไม่มีคำแปล เพิ่มลงใน `comments.en.json` แล้วรัน `python3 tools/i18n/comments.py apply` คำสั่ง `apply` รันซ้ำได้ และคงรูปแบบท้ายบรรทัด (CRLF/LF) กับ BOM ของไฟล์ไว้ ส่วน `strip` ลบบรรทัดภาษาอังกฤษออกทั้งหมด (ย้อนกลับได้ตรงทุกไบต์) คำแปลที่ขึ้นต้นด้วย `@inline ` จะต่อท้ายบรรทัดเดิม ใช้กับบรรทัด marker ที่ script ค้นหา เช่น `# SOCLAB-BEGIN` เพื่อให้รัน script ซ้ำแล้วไม่มีบรรทัดเกินค้าง
- **diagram ใหม่หรือที่แก้**: เพิ่มข้อความไทยใหม่ลงใน `diagrams.en.json` แล้วสร้างชุดภาษาอังกฤษใหม่ (ต้องมี Node และ playwright ตั้ง `FONT_DIR` ชี้ไปที่ไฟล์ `.woff2` ของ Sarabun และ JetBrains Mono)

  ```bash
  NODE_PATH=<dir>/node_modules FONT_DIR=<fonts dir> node tools/i18n/diagrams-en.js
  ```

  ข้อความที่แปลแล้วถูกวัดขนาดใน Chromium ถ้ากว้างเกินทั้งกรอบและข้อความไทยเดิม จะลดขนาดตัวอักษรลงจนพอดี (ต่ำสุด 60%) และรายงานจำนวนที่ลดขนาด รวมถึงข้อความที่ยังล้นกรอบ
- **เอกสาร**: แก้ทั้ง `X.md` และ `X.th.md` คำสั่งใน code block ต้องเหมือนกันทั้งสองภาษา แปลเฉพาะ comment และเนื้อความ
- **ไฟล์ใน `chNN-*/files/`**: สร้างจากหนังสือด้วย `export-files.js` ซึ่งเขียน README ทั้งสองภาษาและรัน `comments.py apply` ให้ด้วย จึงให้สร้างใหม่แทนการแก้มือ
